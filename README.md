# package-trocr-inference
Package for performing inference and evaluation for OCR/HTR tasks with HuggingFace integration.

## Requirements

- Python >= 3.12
- PyTorch >= 2.6
- CUDA compatible GPU (recommended, but CPU also supported)

## Installation

### Option 1: Install with pip

```bash
git clone https://github.com/The-Flow-Project/package-trocr-inference.git
cd package-trocr-inference
pip install .
```

### Option 2: Install with uv (recommended)

```bash
git clone https://github.com/The-Flow-Project/package-trocr-inference.git
cd package-trocr-inference
uv pip install .
```
